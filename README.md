# GuessDotPie on C++!

in this project i am trying to remake my old python project but this time i am doing it in C++! a completely new language for me, i will try to make it in terminal at first, then i will make it in discord, This is my first C++ project! 

## Features:

### 1. flip:
a simple game where there's a 50/50 chance of you doubling your bet or losing it.

### 2. roll:
a game where you pick a target, a bet and a direction, the game randomly picks a number (1-100), if that number was over your target and you picked over; you win. the multiplier is calculated by how risky your play was, for example: a game with over and the target is 75 is more risky than a game with under and a target of 90.

### 3. hilo:
a game where a number is randomly picked (1-13) the first number is randomly generated, you chose wether the next randomly generated number will be over/under that number. the multiplier increases by 1.1x until you cash out.
